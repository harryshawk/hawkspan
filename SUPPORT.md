# Support

Use GitHub Issues for reproducible bugs, installation problems, and feature
requests. Select the matching issue form and provide only sanitized diagnostic
information.

Before reporting an installation problem, run `scripts/check-release.sh` and
follow `INSTALL.md`. Include the HawkSpan tag, commit, or exact `release_id`
from `release/release-manifest.json`, along with macOS, Mac architecture, and
Node.js versions.

Never publish usernames, hostnames, private addresses, SSH material, personal
paths, message contents, application workload data, or private configuration.
Report vulnerabilities through the repository's private vulnerability
reporting channel instead of a public issue.
